### About the Experiment 

This experiment helps learners implement and visualize the Ford–Fulkerson algorithm to compute maximum flow in a directed network. Users can initialize a flow graph, discover augmenting paths using DFS or BFS (Edmonds–Karp variant), and observe residual graph updates, bottleneck capacities, and flow augmentation at each step. The simulation also demonstrates the Max-Flow Min-Cut theorem and enables performance comparison across different network sizes.
